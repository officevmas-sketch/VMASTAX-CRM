# VMAS CRM - Power BI Style Dashboard UI

Run locally:

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Added in this version
- Power BI style executive dashboard
- Compact KPI cards
- Executive Summary, Revenue & Recovery, Compliance Workload, and Follow-up Control tabs
- Proper slicer/filter display
- Amount display toggle: Absolute, Thousands, Lakhs, Crores
- Bright professional white/navy/gold UI
- Existing client workspace, import/export, registrations, WhatsApp follow-up links retained
