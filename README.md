# VMAS Tax Solutions CRM

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Default login
- Username: `admin`
- Password: `admin123`

Change the admin password after first login.

## User rights
Admin can create users and assign page-wise rights:
- Executive Dashboard
- Client Workspace
- Lead Pipeline
- Follow-ups
- Add / Edit Client
- Import / Export
- User Management
